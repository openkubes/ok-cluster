# OpenKubes CAPI Architecture Decision Records

This directory stores the seven independent, accepted OpenKubes CAPI/BYOH architecture decisions.

See [the CAPI architecture index](../README.md) for the decision list and publication/evidence rules.

## ADR Conventions

- Decisions are immutable historical records of accepted architectural intent; any substantive change should be reviewed, with amended/superseding records clearly identified.
- `Accepted` describes the architecture decision, not implementation readiness.
- The `ADR-CAPI-NNN` numbering is separate from other ADR series.
- Do not imply complete E2E validation without explicit evidence.
- Avoid references to earlier platform-specific ADRs; these records describe the new architecture independently.
